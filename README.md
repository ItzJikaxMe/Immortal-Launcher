# Immortal Launcher

An Android launcher for Minecraft: Java Edition, built with Java.

## Current stage

- Initial Android application structure
- Java 17
- Landscape launcher interface prototype inspired by the supplied reference
- Version selection, accounts, mods, wardrobe and game launch are UI placeholders

## Important

This first commit is the interface foundation only. It does not yet download or run Minecraft.
A compatible Java runtime, Minecraft asset/library installer, authentication flow, and Android graphics/input compatibility layer still need to be implemented and tested.

## Build

Open this project in Android Studio and sync with Gradle. Use JDK 17.
